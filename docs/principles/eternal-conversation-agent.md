# 永续会话 Agent 第一原则

> 本文只约束特性目标，防止开发漂移；不规定具体架构、实现方式或评测方案。

## 第一原则

> **记忆的价值不在于复原过去，而在于保持未来行为。**

永续会话 Agent 的目标是：

> **无论会话持续多久，Agent 都能延续完整历史形成的有效认知，在未来对话和行动中保持连续、一致。**

这里需要延续的包括：

- 用户身份、偏好和关系；
- 长期目标、当前任务和未完成事项；
- 已确认的事实、决定、承诺和约束；
- 过去交互对未来判断、回复与行动仍然有效的影响。

## 原则公式

设 \(H_t\) 为时刻 \(t\) 永续会话系统能够观察到的、可能影响未来行为的完整交互历史，\(M_t\) 为系统维护的有限常驻行为状态，\(L_t\) 为已经发布、可按需检索的 Long-term Memory，\(E_t\) 为独立保存并可按需访问的 Raw History 证据层，\(x\) 为未来可能出现的输入，\(\pi\) 为 Agent 的行为策略。\(L_t\) 和 \(E_t\) 都不计入 \(|M_t|\)；\(M_t\) 只包含有限常驻状态，以及发现和访问 \(L_t\) 与 \(E_t\) 所需的有限能力。\(E_t\) 不自动注入当前上下文，只在 Long-term Memory 与常驻状态不足时作为证据查询。第一原则要求：

\[
\pi(\cdot \mid H_t, x) \approx \pi(\cdot \mid M_t, L_t, E_t, x)
\]

即：面对未来输入时，使用有限常驻状态、可检索 Long-term Memory 和独立按需证据层的 Agent，应当与拥有完整历史的 Agent 保持实质一致的行为。

这里的“完整”以永续会话系统的可观察边界为限，至少包括前台 Agent 的全部模型可见输入、模型输出、工具交互和显式行为相关状态。凡是已经进入前台模型可见输入或由宿主明确暴露给 Harness 的行为相关内容，都必须进入完整历史并原样持久化。模型内部推理和模型供应商未暴露的隐藏状态不属于永续会话的保证范围；接入方不得把未暴露的信息默认为已经受到记忆保障。

特性的目标可以写为：

\[
\min |M_t|
\quad \text{subject to} \quad
D_{behavior}(H_t, M_t, L_t, E_t) \le \epsilon
\]

即：在未来行为偏差不超过可接受范围的前提下，使常驻行为状态保持有限。\(L_t\) 不计入 \(|M_t|\) 不代表可以无限积累无价值记忆；Long-term Memory 是否保留一项内容，仍由它是否可能影响未来行为决定。公式用于固定特性目标，不规定如何压缩、存储、检索或评测。

## 不可偏离的边界

1. 永续会话追求的是**行为连续性**，不是历史文本的完整复述。
2. 会话变长后，Agent 不能因为早期内容离开当前上下文，就遗忘仍然有效的信息或违背既有约束。
3. 任何压缩、摘要、检索、记忆或存储方案都只是实现手段，不能被当成特性目标。
4. 降低 token、缩短上下文或提高摘要质量，若损害未来行为连续性，就不算成功。
5. 是否保留一项信息，应以它是否仍可能影响未来行为为准，而不是仅以时间远近、出现频率或摘要便利性为准。

## 防漂移约束

开发永续会话相关特性时，必须遵守：

1. 改动必须增强或维持 Agent 对完整历史所形成有效认知的延续能力。
2. 改动不得让 Agent 遗忘仍然有效的事实、目标、承诺或约束。
3. 局部实现指标必须服务于永续会话的目标，不能取代未来行为连续性成为优化目标。

如果一项改动改善了局部指标，却削弱了未来行为的连续性，它就偏离了第一原则。
